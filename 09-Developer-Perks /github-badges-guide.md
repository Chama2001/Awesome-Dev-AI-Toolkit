# 🏆 GitHub Badges Guide

Badges make your GitHub profile and repositories look professional and trustworthy. Here is a quick guide on how to add them.

## 1. Repository Shields (Shields.io)
You can add dynamic badges to your `README.md` to show the build status, version, license, or social metrics.

**Standard Badges:**
```markdown
![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)
![PRs Welcome](https://img.shields.io/badge/PRs-welcome-brightgreen.svg)
![Maintained](https://img.shields.io/badge/Maintained%3F-yes-green.svg)
```

**Social Badges:**
Replace `[YourUsername]` and `[YourRepo]` with your actual GitHub details.
```markdown
![GitHub stars](https://img.shields.io/github/stars/[YourUsername]/[YourRepo]?style=social)
![GitHub followers](https://img.shields.io/github/followers/[YourUsername]?style=social)
```

## 2. Official GitHub Profile Achievements
GitHub automatically awards these badges to your profile based on your activity:
*   **Pull Shark:** Open 2 pull requests that get merged into a repository you don't own.
*   **YOLO:** Merge a pull request without code review.
*   **Quickdraw:** Close an issue or a pull request within 5 minutes of opening.
*   **Starstruck:** Create a repository that receives 16 stars.
*   **Galaxy Brain:** Have 2 discussions marked as answers.

Displaying these shows your active participation in the open-source community!
