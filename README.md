## 📂 Directory Structure

### 🧠 01-Prompt-Engineering
Ready-to-use prompts for code generation, debugging, and structuring complex JSON data efficiently.

### 🔌 02-Free-AI-APIs
Snippets and guides for utilizing free tiers of popular AI APIs like Google Gemini, OpenAI, and various Vector Databases.

### 💻 03-Local-AI-Models
Setup guides for running models completely offline using HuggingFace, Ollama, and LM Studio.

### 👁️ 04-Computer-Vision
Scripts and configurations for image classification (EfficientNet) and real-time computer vision tasks (MediaPipe & OpenCV).

### 🏗️ 05-Advanced-LLM-Architecture
Concepts and implementation basics for RAG (Retrieval-Augmented Generation), LLM Caching, Quantization, and LoRA Fine-tuning.

### 🛡️ 06-AI-Guardrails
Best practices and techniques for content filtering and preventing prompt injection attacks in your AI apps.

### 🤖 07-Custom-Chatbots
Resources for building domain-specific chatbots using AI Agents, Python Flask, SQLite, and FastAPI.

### 🎨 08-Frontend-UI-Prompts
Prompts tailored for generating modern UI components with Next.js 15, Tailwind CSS v4, React, and Framer Motion animations.

### 🎁 09-Developer-Perks
A collection of developer benefits, including guides to earning GitHub badges, tech speaking scripts, and securing Azure free vouchers.
