# 🎨 Next.js 15 & Tailwind v4 Prompts

Use these prompts with an AI coding assistant (like Gemini 1.5 Pro, Claude 3.5 Sonnet, or v0) to generate modern, responsive, and accessible UI components.

## 1. Hero Section Generation
**Prompt:**
> "Generate a modern Hero Section for a SaaS landing page using Next.js 15 (App Router) and Tailwind CSS v4. 
> Requirements:
> - A bold headline, a subheadline, and two call-to-action buttons (Primary and Secondary).
> - Use a dark mode first approach with a subtle gradient background.
> - Make it fully responsive (mobile, tablet, desktop).
> - Use Lucide React for icons.
> Provide only the standard functional React component code."

## 2. Interactive Data Table
**Prompt:**
> "Create a reusable Data Table component in Next.js 15 using React 19 server/client components.
> Requirements:
> - Styled with Tailwind CSS v4.
> - Must include basic search filtering and pagination UI.
> - Table columns: Name, Role, Status (with color-coded badges: Active/Green, Pending/Yellow), and Actions.
> - Ensure the table is scrollable horizontally on smaller screens.
> Please provide the clean, production-ready code."
