## [1.0.1] - 2026-10-12
### Added
- Added `10-GitHub-Actions` folder with a comprehensive Python CI workflow.
- Included Grad-CAM visualization script for Explainable AI in Computer Vision.
- Added Ollama setup guide for running large language models locally.
- Included Microsoft Copilot Studio basics for building low-code AI agents.
- Added a 5-minute technical speaking script template for developers.

### Fixed
- Fixed markdown formatting issues in HuggingFace code snippets to ensure proper syntax highlighting.

## [1.0.0] - 2026-10-10
### Added
- Initial release of the Awesome-Dev-AI-Toolkit.
- Created 9 core directories covering Prompt Engineering, Local AI, Computer Vision, Advanced LLM Architecture (RAG), AI Guardrails, and Frontend UI prompts.
- Added MIT License, README, and Contributing guidelines.
